## 1. Objetivo

Garantir que os dados pessoais coletados pela empresa sejam utilizados de forma correta e segura. Caso seja necessário usar esses dados para uma finalidade diferente da original, a empresa deverá verificar se esse novo uso é permitido pela Lei Geral de Proteção de Dados (LGPD).

## 2. A quem se aplica

Esta política se aplica a todos os funcionários, setores e prestadores de serviços que tenham acesso aos dados pessoais armazenados ou utilizados pela empresa.

## 3. Regras

3.1

Antes de utilizar dados pessoais para uma nova finalidade, o setor solicitante deverá preencher um formulário informando a nova finalidade, o motivo do uso e a base legal utilizada. O formulário deverá ser registrado no inventário de tratamento de dados.

3.2

O Encarregado de Proteção de Dados deverá avaliar se o novo uso é permitido pela LGPD e se é compatível com a finalidade original. O resultado da avaliação deverá ser registrado no formulário, com a data e a justificativa da decisão.

3.3

O novo uso dos dados só poderá começar após a avaliação favorável do Encarregado de Proteção de Dados e a autorização do Diretor Executivo. Caso a solicitação seja negada, os dados não poderão ser utilizados para a nova finalidade.

## 4. Como o cumprimento e verificado

A cada três meses, o Encarregado de Proteção de Dados deverá conferir os formulários registrados no inventário de tratamento de dados, verificando se possuem a finalidade, a base legal, a avaliação realizada e a autorização necessária.
O resultado dessa conferência deverá ser registrado em um relatório, contendo a data, as avaliações verificadas e possíveis problemas encontrados.
A política será revisada anualmente para garantir que continue adequada às regras da LGPD.
