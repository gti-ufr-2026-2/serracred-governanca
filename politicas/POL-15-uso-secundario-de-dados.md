## 1. Objetivo

Garantir que os dados pessoais coletados pela empresa sejam utilizados de forma correta e segura. Caso seja necessário usar esses dados para uma finalidade diferente da original, a empresa deverá verificar se esse novo uso é permitido pela Lei Geral de Proteção de Dados (LGPD).

## 2. A quem se aplica

Esta política se aplica a todos os funcionários, setores e prestadores de serviços que tenham acesso aos dados pessoais armazenados ou utilizados pela empresa.

## 3. Regras

*3.1 Solicitação de novo uso*

Antes de utilizar dados pessoais para uma nova finalidade, o setor solicitante deverá preencher um formulário contendo:

- Número de identificação da solicitação;
- Data da solicitação e setor responsável;
- Finalidade original e nova finalidade dos dados;
- Motivo do novo uso e base legal utilizada.

O formulário deverá ser armazenado no inventário de tratamento de dados da empresa antes do início do novo uso.

*3.2 Avaliação da solicitação*

O Encarregado de Proteção de Dados deverá analisar o formulário e verificar se existe uma base legal válida, se o novo uso é compatível com a finalidade original e se respeita os direitos dos titulares.
O resultado deverá ser registrado no próprio formulário, contendo a data, a justificativa e a identificação do responsável pela avaliação.

*3.3 Autorização do novo uso*

O novo uso dos dados só poderá começar após a avaliação favorável do Encarregado de Proteção de Dados e a autorização do Diretor Executivo.
A autorização deverá ser registrada no formulário, com a data e a identificação do aprovador. Solicitações negadas ou sem autorização não poderão ser executadas.

## 4. Como o cumprimento e verificado

A cada três meses, o Encarregado de Proteção de Dados deverá conferir os registros de novos usos de dados realizados no período, verificando:
- Se existe um formulário para cada novo uso identificado;
- Se os formulários possuem todas as informações obrigatórias;
- Se a avaliação e a autorização ocorreram antes do início do novo uso;
- Se as solicitações negadas não foram executadas.
  
O resultado da conferência deverá ser registrado em um relatório trimestral, contendo a data, os registros analisados, os problemas encontrados e as correções necessárias.
Os formulários e relatórios deverão ficar armazenados no inventário de tratamento de dados, permitindo sua consulta em auditorias.
A política será revisada anualmente.
