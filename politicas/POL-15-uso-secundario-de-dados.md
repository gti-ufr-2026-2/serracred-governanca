## 1. Objetivo

Garantir que os dados pessoais coletados pela empresa sejam utilizados de forma correta e segura. Caso seja necessário usar esses dados para uma finalidade diferente da original, a empresa deverá verificar se esse novo uso é permitido pela Lei Geral de Proteção de Dados (LGPD).

## 2. A quem se aplica

Esta política se aplica a todos os funcionários, setores e prestadores de serviços que tenham acesso aos dados pessoais armazenados ou utilizados pela empresa.

## 3. Regras

3.1

Antes de utilizar dados pessoais para uma nova finalidade, o setor responsável deverá informar o motivo desse uso e verificar se existe uma base legal que o permita.

3.2

O novo uso dos dados deverá ser avaliado para garantir que seja compatível com a finalidade original da coleta e que não prejudique os direitos dos titulares.

3.3

Toda avaliação deverá ser registrada em um documento, contendo a nova finalidade, a base legal utilizada e a autorização do responsável. Caso o uso não seja permitido, ele não poderá ser realizado.

## 4. Como o cumprimento e verificado

O Encarregado de proteção de dados deverá verificar os registros das avaliações realizadas, conferindo se os novos usos possuem uma base legal e se são compatíveis com a finalidade original.
