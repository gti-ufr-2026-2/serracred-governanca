## 1. Objetivo

Estabelecer critérios para avaliar e autorizar o uso de dados pessoais já mantidos pela SERRACRED para uma finalidade diferente daquela para a qual foram coletados.

## 2. A quem se aplica

Aplica-se a todas as áreas da SERRACRED que solicitem ou executem o uso de dados pessoais para uma nova finalidade, incluindo dados de cooperados, colaboradores e prestadores de serviços.

## 3. Regras

**3.1. Registrar a solicitação:** Antes de iniciar o novo uso, a área interessada deve registrar a finalidade original, a nova finalidade, os dados necessários e a justificativa para sua utilização. Por exemplo, se a área comercial quiser usar o histórico de transações para selecionar cooperados que receberão ofertas de crédito, deve registrar essa finalidade e indicar quais informações do histórico pretende usar.

**3.2. Avaliar a base legal e a compatibilidade:** O Gerente de Conformidade deve identificar a base legal aplicável à nova finalidade e documentar a avaliação de compatibilidade. A análise deve considerar a relação entre as finalidades, o que os titulares poderiam razoavelmente esperar, os possíveis impactos para eles e as medidas de proteção previstas.

**3.3. Registrar a decisão antes do uso:** O Gerente de Conformidade deve registrar a aprovação ou a recusa da solicitação, com data e justificativa. A área solicitante só pode iniciar o novo uso após a aprovação, condicionada à existência de base legal aplicável e a uma avaliação favorável de compatibilidade. O uso autorizado deve se limitar aos dados e à finalidade descritos na decisão.

## 4. Como o cumprimento é verificado

A área de Conformidade deve verificar, em amostra dos usos secundários iniciados no período, se há registro da solicitação, da base legal, da avaliação de compatibilidade e da decisão fundamentada. A verificação deve comparar a data de aprovação com a data de início do uso e conferir se os dados utilizados correspondem aos autorizados. As divergências devem ser registradas com responsável e prazo para correção.
